# Engenharia de Software 2

Repositório destinado ao armazenamento e à organização das atividades, exercícios e trabalhos desenvolvidos durante a disciplina de **Engenharia de Software 2**, da Pontifícia Universidade Católica de Minas Gerais (PUC Minas).

## 📚 Sobre a disciplina

Este repositório reúne as atividades práticas e teóricas propostas pelo professor ao longo do semestre, servindo como registro do aprendizado e da evolução dos conhecimentos adquiridos na disciplina.

## 📂 Organização do repositório

As atividades serão organizadas em diretórios, facilitando a identificação e a consulta de cada entrega.

## 🛠️ Tecnologias e ferramentas

As tecnologias e ferramentas utilizadas poderão variar de acordo com os requisitos de cada atividade.
